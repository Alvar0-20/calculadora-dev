# 🧮 Calculadora Dev

Uma aplicação web interativa desenvolvida com **HTML5**, **CSS3** e **JavaScript**, projetada para ir muito além de uma calculadora básica. O projeto conta com um painel estilo dashboard que integra ferramentas de estudo, conceitos essenciais de programação e fórmulas matemáticas úteis.

---

## ✨ Funcionalidades

* **Modo Básico e Científico:** Alternância dinâmica entre operações aritméticas comuns e funções científicas avançadas (como raiz quadrada, potência, seno, cosseno, tangente e constante $\pi$).
* **Suporte Completo ao Teclado:** Permite realizar cálculos diretamente pelo teclado do PC (números, operadores, `Enter` para calcular, `Backspace` para apagar e `Escape` para limpar).
* **Painéis Laterais Educativos (Dashboard):** 
  * 📖 **Dicionário Dev:** Conceitos essenciais de desenvolvimento web (DOM, Eval, Grid, Event Listeners, etc.).
  * 📐 **Fórmulas Úteis:** Fórmulas matemáticas e físicas importantes de acesso rápido.
* **Design Responsivo & Fluido:** Fundo com gradiente animado em movimento e layout adaptado tanto para computadores quanto para dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação e dos painéis informativos.
* **CSS3:** Estilização avançada com Flexbox, Grid Layout, efeitos de vidro fosco (*backdrop-filter*) e animações com `@keyframes`.
* **JavaScript (ES6):** Manipulação do DOM, funções lógicas para operações e escutadores de eventos de teclado (*EventListeners*).
